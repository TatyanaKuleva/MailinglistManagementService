Mailing List Management Service 📧

Описание:
Приложение для управления клиентами, сообщениями и рассылками с поддержкой регистрации пользователей и системой ролей. 
Позволяет создавать, редактировать и запускать рассылки, отслеживать статистику отправки и управлять доступом к данным 
в зависимости от роли пользователя.

Функионал:
- Управление клиентами, сообщениями и рассылками через веб-интерфейс.
- Запуск и управление рассылками с ручным стартом и логированием попыток.
- Регистрация новых пользователей и управление ролями через админ-панель.
- Просмотр отчетов и статистики в профиле пользователя.

Предварительные требования:

- Python 3.8+
- Poetry (для управления зависимостями)
- Redis (для кеширования и очередей, если используется)
- SMTP-сервер или настройки для отправки почты
